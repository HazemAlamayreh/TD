# Talent Development Adaptive Academy

## Version 15 — preparation for GitHub Pages

This repository is intended to host the standalone Talent Development Adaptive Academy covering Domains 1, 2 and 3.

### Publish the course

Upload the prepared v15 HTML course file to the root of this repository and name it **index.html**. GitHub Pages requires an index page at its configured source.

1. Open **Add file → Upload files** and upload the standalone v15 HTML file, renaming it to `index.html` before upload if needed.
2. Go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
3. Test the GitHub Pages address provided under Settings → Pages.
4. For the future custom domain `academy.idevelopmena.com`, add a DNS CNAME pointing to `HazemAlamayreh.github.io` in the domain DNS provider, then configure the same custom domain in GitHub Pages. Do this only after Pages is working and DNS has been planned.

### Notes

- Publishing the HTML on GitHub Pages makes the course available publicly. Review licensing and redistribution rights before publishing.
- Learning progress is saved in each browser's local storage and is not synchronized between devices.
- This README does not enable GitHub Pages or configure DNS.
